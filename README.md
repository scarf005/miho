# 미호

구미호 미호가 9층짜리 천상누각을 올라 꼭대기의 영약을 찾는 로그라이크입니다. 층을 오를 때마다 꼬리가 하나씩 늘고, 음양오행 부적을 엮어 주문을 만듭니다.

## 플레이

- [itch.io](https://scarf005.itch.io/miho): Linux, Windows, macOS, Android, 웹
- [개발 빌드](https://scarf005.github.io/miho/): `main`의 최신 웹 빌드

한국어, English, 日本語를 지원합니다.

## 소스에서 실행

필요한 것: [Godot 4.7.2](https://godotengine.org/download/archive/4.7.2-stable/), Rust, [just](https://github.com/casey/just)

```sh
just run    # Rust 확장을 빌드하고 게임을 실행
just test   # 규칙 테스트
just        # 전체 명령 목록
```

`godot`이 `PATH`에 없으면 `GODOT` 환경 변수로 경로를 지정합니다.
