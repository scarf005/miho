# 지형 개편 계획

천상누각의 층마다 지형이 달라서, 같은 빛과 소리 규칙이 층마다 다른 수를 만들게 한다. Brogue CE처럼 지형마다 성질을 표 한 줄로 두고, 층을 만들 때 그 표에서 고른다.

원칙:
- 들고 다니는 물건은 만들지 않는다. 지형은 그 자리에서만 쓴다.
- 모든 지형의 성질은 마우스를 올리면 보인다. 정보창 문구는 지형 표에서 만든다. 표에 없는 규칙은 없다.
- 새 지형은 빛, 소리, 냄새, 불, 물, 하늘 중 하나 이상과 닿는다.

참고한 Brogue CE 소스 (커밋 [363440c](https://github.com/tmewett/BrogueCE/tree/363440c454ee65bb7c1d8eb6c51b65de2a86426c)):
- 지형 성질 표: `tileCatalog`, [Globals.c:315](https://github.com/tmewett/BrogueCE/blob/363440c454ee65bb7c1d8eb6c51b65de2a86426c/src/brogue/Globals.c#L315). 성질 깃발: `T_*`, `TM_*` ([Rogue.h:1903](https://github.com/tmewett/BrogueCE/blob/363440c454ee65bb7c1d8eb6c51b65de2a86426c/src/brogue/Rogue.h#L1903)).
- 층 4개: 바닥, 액체, 기체, 표면 ([Rogue.h:1286](https://github.com/tmewett/BrogueCE/blob/363440c454ee65bb7c1d8eb6c51b65de2a86426c/src/brogue/Rogue.h#L1286)).
- 깊이별 자동 배치 표: `autoGeneratorCatalog`, [GlobalsBrogue.c:113](https://github.com/tmewett/BrogueCE/blob/363440c454ee65bb7c1d8eb6c51b65de2a86426c/src/variants/GlobalsBrogue.c#L113). 개수 = (절편 + 깊이 × 기울기) / 100, 최대값까지.
- 기체 퍼짐: `updateVolumetricMedia`, [Time.c:1247](https://github.com/tmewett/BrogueCE/blob/363440c454ee65bb7c1d8eb6c51b65de2a86426c/src/brogue/Time.c#L1247). 칸마다 이웃 8칸과 양을 평균 내고, 종류에 따라 매 라운드 20% 또는 50% 확률로 1씩 줄어든다.

## 구조

1. 지형 표
   - 칸 종류마다 성질을 한 줄에 둔다.
   - 성질: 걷기, 시야, 빛 통과, 탐(번질 확률), 다 타면 무엇이 되는가, 불을 끔, 묶음, 피해, 숨김, 밟을 때 소리(글자와 칸 수), 냄새 끊김, 빛(반지름과 색), 밟으면 바뀜, 떨어짐.
   - 지금 흩어진 `Terrain.wall`, `World.WALKABLE`, `FLAMMABLE`, `Masks` 표는 모두 이 표에서 만든다. Rust 마스크도 이 표에서 만든 바이트 표를 그대로 쓴다.
2. 층 셋
   - 바닥: 지금의 칸.
   - 표면: 풀, 재, 숯불, 덩굴, 시체 자국처럼 바닥 위에 얹힌 것.
   - 기체: 칸마다 양(0–9)과 종류. 안개, 증기, 연기, 늪 가스, 향 연기.
3. 배치 표
   - 줄마다: 무엇을, 어떤 바닥 위에, 몇 단계(1–9)부터 몇 단계까지, 빈도, 개수(절편, 기울기, 최대).
   - 방 하나를 덩어리로 채울 때는 Brogue처럼 시작 칸에서 퍼질 확률을 칸마다 줄여 가며 넓힌다.
4. 짜인 방
   - 층마다 하나, 열쇠나 물건 없이 지형만으로 된 방을 놓는다.

## 지형

### 풀과 바닥 (표면)

| 지형 | 규칙 | 닿는 시스템 |
|---|---|---|
| 풀 | 탄다(번질 확률 15%). 조용하다 | 불 |
| 마른 짚 | 인화성. 초당 2칸 번지고 맹렬한 불로 탄다 | 불 |
| 갈대 | 시야를 막는다. 밟으면 쓰러져 시야가 트인다. 바스락 2칸. 인화성 | 시야, 소리, 불 |
| 낙엽 | 밟으면 바스락 2칸. 인화성 | 소리, 불 |
| 야광 이끼 | 주위 1칸을 밝힌다 | 빛 |
| 덩굴 | 들어서면 1초 묶인다. 탄다 | 묶임, 불 |
| 숯불 | 빛 1칸. 탈 것이 이웃이면 불이 옮는다. 3초 뒤 재 | 빛, 불 |

### 물

| 지형 | 규칙 | 닿는 시스템 |
|---|---|---|
| 깊은 물 | 지금과 같다. 걸을 수 없고 주문은 넘어간다 | 길 |
| 얕은 물 | 걸을 수 있다. 철벅 2칸. 냄새가 끊긴다. 불이 붙지 않는다. 들어서면 젖는다 | 소리, 냄새, 불 |
| 늪 | 걷는 데 2초. 발소리가 없다. 가끔 늪 가스를 뿜는다 | 소리, 기체 |
| 얼음 | 서리로 언 물. 들어서면 같은 방향으로 1칸 더 미끄러진다 | 밀기 |

### 기체

| 기체 | 규칙 | 흩어짐 |
|---|---|---|
| 안개 | 시야를 막는다 | 느림 (20%) |
| 증기 | 시야를 막고 매초 피해 1. 젖게 한다 | 빠름 (50%) |
| 연기 | 불이 내는 기체. 시야를 막는다 | 빠름 |
| 늪 가스 | 보이지 않는다. 불이 닿으면 터져 칸마다 피해 2 | 느림 |
| 향 연기 | 냄새 자취를 지운다 | 느림 |

### 함정

함정은 밝은 칸이나 바로 옆에서만 보인다. 어두운 칸의 함정은 모른 채 밟는다.

미호, 추격 중인 적, 지나가는 투사체가 함정을 작동시킨다. 추격 중이 아닌 적과 아군은 함정을 돌아간다.

| 함정 | 작동하면 |
|---|---|
| 징 함정 | 징 소리가 층 전체에 퍼지고, 모든 적이 그 칸을 수색한다 |
| 허방다리 | 하늘로 떨어진다. 적과 투사체는 사라지고 미호는 한 층 아래로 간다 |
| 불씨 함정 | 앞으로 불을 뿜는다 |
| 덩굴 함정 | 주위 3×3에 덩굴이 자란다 |

### 구조물

| 구조물 | 규칙 | 닿는 시스템 |
|---|---|---|
| 기둥 | 길과 시야를 막는다. 부서지지 않는다. 숨는 엄폐물이다 | 시야 |
| 병풍 | 시야를 막는다. 걸어서 밀면 쓰러져 쿵 소리를 낸다. 탄다 | 시야, 소리, 불 |
| 장독 | 길을 막는다. 부수면 쨍그랑 소리가 나고, 층을 만들 때 정해진 것이 나온다: 아무것도 없음, 물, 김치, 제웅, 허수아비. 제웅은 찢어지며 미호에게 저주를 하나 건다: 저승사자가 일찍 옴, 적의 어두운 곳 시야가 늘어남, 시체가 1초 뒤 적으로 되살아남 | 소리, 물, 냄새, 수색, 시야 |
| 향로 | 주위에 향 연기를 피운다. 넘어뜨리면 숯불이 쏟아진다 | 냄새, 불 |
| 석등 | 꺼지지 않는 등불. 부서지지 않는다 | 빛 |
| 마당 | 지붕 없는 바닥. 달빛으로 늘 밝다 | 빛 |

### 짜인 방

| 방 | 내용 | 단계 |
|---|---|---|
| 갈대 정원 | 갈대가 방을 채우고, 가운데에 얕은 물이 있다 | 1– |
| 불타기 쉬운 곳간 | 마른 짚이 깔리고 향로가 있다 | 2– |
| 안개 연못 | 깊은 물이 안개를 피운다 | 3– |
| 경보 복도 | 어두운 복도에 징 함정이 여럿 있다 | 4– |
| 깨어나는 석상 | 장승 석상들이 미호가 지나가면 깨어난다 | 5– |
| 무너지는 마루 | 방 바닥이 차례로 꺼져 하늘이 된다 | 6– |
| 늪지 | 늪과 늪 가스가 있다 | 7– |

## 단계

1. 지형 표로 바꾼다. 규칙은 그대로 두고, 정보창 지형 문구를 표에서 만든다. 지금 있는 시험이 모두 그대로 통과해야 한다.
2. 표면 층과 배치 표. 풀, 마른 짚, 갈대, 낙엽, 얕은 물, 기둥.
3. 기체 층과 퍼짐. 안개, 연기, 증기. 주문 계획의 증기와 진흙이 이 층을 쓴다. `just bench`에서 라운드당 0.5 ms를 넘으면 Rust로 옮긴다.
4. 함정과 빛에 따른 보임.
5. 구조물.
6. 짜인 방.
7. MCP로 여러 판을 돌려 단계별로 지형이 너무 많거나 적은지 잰다.
